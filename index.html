    Use o botão ★ Salvar no mapa para guardar a vista atual (local, camada e modelo). Fica salvo só neste navegador.

      Como funciona

      Os dados brutos vêm dos modelos GFS (NOAA, ~25 km) e ICON (DWD, ~13 km), via Open-Meteo. Os índices de voo (teto de térmica, força, potencial XC etc.) são calculados aqui mesmo, no navegador, com o método da parcela e a escala convectiva de Deardorff.

      Clique em qualquer ponto do mapa para ver o dia hora a hora, a sondagem (Skew-T) e a comparação entre os modelos.

      Limites

      Modelos globais não enxergam detalhes de relevo, brisa marítima nem convecção local. Use como orientação, nunca como única base para decidir um voo.
